# Capturas para la entrega

La sesión de desarrollo no tiene ningún navegador disponible para capturar imágenes. Para completar este entregable, inicia la aplicación y toma capturas reales (no recreadas) con estos nombres dentro de esta carpeta:

1. Abre `http://127.0.0.1:8085` y captura el resumen y la lista del catálogo como `inicio.png`.
2. En la misma página, captura el catálogo con el formulario y existencias visibles como `libros.png`.
3. Captura el formulario de alta de libro con datos ficticios rellenados antes de guardar como `registro-libro.png`.
4. Selecciona **Editar** en un libro, captura el formulario con un valor modificable como `edicion-libro.png`.
5. Entra a **Usuarios** y captura el directorio como `usuarios.png`.
6. Entra a **Préstamos** y captura el formulario de préstamo con opciones disponibles como `registro-prestamo.png`.
7. Captura el historial con un préstamo activo como `prestamos.png`.
8. Captura el estado devuelto después de seleccionar **Registrar devolución** y confirmar como `devolucion.png`.

Utiliza exclusivamente los ejemplos ficticios incluidos por el SQL. No muestres credenciales ni datos personales reales. Conserva el encuadre de la aplicación y una imagen de escritorio legible; toma también una imagen con el navegador angosto para verificar el diseño adaptable si es posible.
